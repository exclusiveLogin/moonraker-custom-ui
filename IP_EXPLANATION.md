# 🔍 Объяснение IP адресов в конфигурации

## Разница между IP адресами

### 1. IP принтера (Moonraker сервер)
- **Где:** `js/config.js` → `moonrakerUrl: 'http://192.168.31.75:7125'`
- **Что это:** IP адрес устройства, где работает Moonraker (ваш принтер/компьютер с Klipper)
- **Зачем:** Приложение знает, куда отправлять запросы

### 2. IP вашего компьютера (Origin)
- **Где:** `moonraker.conf` → `cors_domains` и `trusted_clients`
- **Что это:** IP адрес компьютера, с которого вы открываете веб-интерфейс
- **Зачем:** Moonraker должен разрешить запросы с этого адреса

## 📋 Как определить IP вашего компьютера

### Windows:
```cmd
ipconfig
```
Ищите строку `IPv4 Address` в разделе вашего сетевого адаптера.

### Linux/Mac:
```bash
ifconfig
# или
ip addr
```

## ✅ Правильная настройка

### В `js/config.js` (IP принтера):
```javascript
moonrakerUrl: 'http://192.168.31.75:7125'  // IP принтера
```

### В `moonraker.conf` (IP вашего компьютера):
```ini
[authorization]
trusted_clients:
    192.168.0.0/16  # ✅ Уже покрывает ваш IP (если он в диапазоне 192.168.x.x)

cors_domains:
    http://localhost:*
    http://127.0.0.1:*
    http://ВАШ_IP_КОМПЬЮТЕРА:*  # ✅ IP вашего компьютера, с которого открываете интерфейс
```

## 🎯 Пример

Допустим:
- **Принтер (Moonraker):** `192.168.31.75:7125`
- **Ваш компьютер:** `192.168.31.100` (где открываете `http://localhost:3000`)

Тогда в `moonraker.conf`:
```ini
cors_domains:
    http://localhost:*
    http://127.0.0.1:*
    http://192.168.31.100:*  # ✅ IP вашего компьютера
```

## ⚠️ Важно

- `cors_domains` = адреса, **с которых** делаются запросы (Origin)
- `trusted_clients` = IP адреса клиентов, **с которых** разрешены запросы
- Оба должны содержать IP **вашего компьютера**, а не принтера!
