# 🔐 Авторизация в Moonraker через WebSocket

## Проблема

Ошибка `-32602 Unauthorized` при использовании WebSocket означает, что авторизация не прошла.

## Способы авторизации

### Способ 1: Токен в URL (текущий)

```javascript
ws://192.168.31.75:7125/websocket?token=ваш-api-ключ
```

**Проблема:** Может не работать с `force_logins: true`

### Способ 2: access.login метод

После подключения WebSocket отправить:

```json
{
  "jsonrpc": "2.0",
  "method": "access.login",
  "params": {
    "username": "_api_key_user_",
    "password": "ваш-api-ключ"
  },
  "id": 1
}
```

### Способ 3: Проверить формат API ключа

Убедитесь, что API ключ правильный:
- Проверьте в `moonraker.conf` - должен совпадать
- Попробуйте получить новый ключ через Moonraker

### Способ 4: Временно отключить force_logins

Для теста попробуйте:

```ini
[authorization]
force_logins: false  # Временно для теста
```

## Проверка

1. Откройте консоль браузера (F12)
2. Проверьте логи подключения
3. Если видите "Authentication failed" - проблема в авторизации
4. Если видите "Unauthorized" в ответе - токен не принимается

## Решение

Попробуйте в таком порядке:
1. Проверьте, что API ключ правильный
2. Попробуйте `access.login` метод
3. Временно отключите `force_logins: false` для теста
4. Проверьте версию Moonraker - обновите, если старая
