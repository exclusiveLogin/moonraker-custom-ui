# 🔧 Решение проблем

## CORS ошибка не исчезает

### Шаг 1: Проверьте конфигурацию Moonraker

Убедитесь, что в `moonraker.conf` добавлены строки в `cors_domains`:

```ini
cors_domains:
    # ... существующие домены ...
    http://localhost:*
    http://127.0.0.1:*
    http://192.168.*.*:*
```

### Шаг 2: Перезапустите Moonraker

**Важно:** После изменения конфигурации Moonraker **обязательно** перезапустите сервис:

```bash
sudo systemctl restart moonraker
```

Или через веб-интерфейс Mainsail/Fluidd:
- Settings → Machine → Restart Moonraker

### Шаг 3: Очистите кеш браузера

**Hard Refresh (обязательно!):**
- **Windows/Linux**: `Ctrl + Shift + R` или `Ctrl + F5`
- **Mac**: `Cmd + Shift + R`

Или:
1. Откройте DevTools (F12)
2. Правый клик на кнопке обновления
3. Выберите "Очистить кеш и жесткая перезагрузка"

### Шаг 4: Проверьте консоль браузера

Откройте консоль разработчика (F12) и проверьте:

1. **Точный текст ошибки CORS**
2. **URL запроса** - должен совпадать с адресом в `cors_domains`
3. **Заголовки ответа** - должны содержать `Access-Control-Allow-Origin`

### Шаг 5: Проверьте IP адрес

Убедитесь, что IP адрес вашего компьютера попадает в диапазон `trusted_clients`:

```bash
# Windows
ipconfig

# Linux/Mac
ifconfig
# или
ip addr
```

Ваш IP должен быть в одном из диапазонов:
- `192.168.0.0/16` ✅ (уже есть в вашем конфиге)
- `10.0.0.0/8` ✅ (уже есть)
- `172.16.0.0/12` ✅ (уже есть)

### Шаг 6: Проверьте логи Moonraker

```bash
# Просмотр логов
sudo journalctl -u moonraker -f

# Или
tail -f ~/printer_data/logs/moonraker.log
```

Ищите ошибки связанные с CORS или авторизацией.

## Другие проблемы

### API ключ не работает

1. Проверьте, что ключ правильный в `js/config.js`
2. Убедитесь, что ключ добавлен в заголовок `X-Api-Key`
3. Проверьте логи Moonraker на ошибки авторизации

### WebSocket не подключается

1. Проверьте, что WebSocket URL правильный
2. Убедитесь, что API ключ передается как `token` в URL
3. Проверьте, что порт 7125 открыт в firewall

### Данные не обновляются

1. Проверьте консоль на ошибки
2. Убедитесь, что WebSocket подключен (зеленый индикатор)
3. Проверьте, что подписка на обновления работает

## Быстрая проверка

Откройте консоль браузера (F12) и выполните:

```javascript
// Проверка доступности API
fetch('http://192.168.31.75:7125/printer/status', {
    headers: {
        'X-Api-Key': 'c0a0a871d7b34951838a3ad2f09491cd'
    }
})
.then(r => r.json())
.then(console.log)
.catch(console.error);
```

Если видите CORS ошибку - проблема в конфигурации Moonraker.
Если видите данные - проблема в коде приложения.
